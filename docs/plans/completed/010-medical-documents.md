# EP-10: Private Leave Request Documents / Medical Certificates

## Goal

Add immutable private document attachments to leave requests, initially supporting `MEDICAL_CERTIFICATE` only.

## Scope

- Persist document metadata in `licenses.leave_request_documents`.
- Store bytes behind `IPrivateDocumentStorage`; local Development uses private filesystem storage.
- Add authenticated backend endpoints for metadata listing, upload, and content streaming.
- Add explicit document permissions independent from request visibility.
- Extend the frontend minimally for metadata display, upload, and secure download.

## Non-goals

- Mandatory certificate policy enforcement.
- OCR, image processing, thumbnails, antivirus integration, public links, Azure SDK integration.
- Document replacement, delete API, retention/deletion rules.

## Implementation notes

- `LeaveRequestDocument` rows are immutable metadata records.
- `StorageKey` is generated by the backend and is never based on user filenames.
- PostgreSQL stores no document bytes.
- Document authorization uses the leave request's stored `OrgUnitId`, not current employee assignment.
- TECH_ADMIN receives no automatic document permissions.

## Validation

Final validation must run backend build/tests, EF pending-model check, frontend lint/typecheck/build, and docker compose config.
